# Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
- В Git ветки создаются быстро, так как они работают локально и не требуют копирования файлов. В SVN ветвление связано с копированием директорий, поэтому оно выполняется медленнее.
# Можно ли в SVN сделать коммит без интернета? Почему?
- Нет. SVN использует централизованный репозиторий, поэтому для выполнения коммита требуется подключение к центральному серверу.
# В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- SVN может использоваться в старых (legacy) проектах, где уже построена инфраструктура на этой системе. В методичке отдельно отмечается, что такие проекты встречаются, в частности, в госсекторе и банках.
